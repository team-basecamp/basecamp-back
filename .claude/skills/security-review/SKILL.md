# Security Review (보안 점검 스킬)

BaseCamp 백엔드 변경분에 대한 보안 점검을 수행한다.

## 절차

1. 변경된 파일 범위를 파악한다 (`git diff` 또는 지정된 파일).
2. `checklist.md`의 항목을 하나씩 대조한다.
3. 발견 사항을 **심각도(높음/중간/낮음)** 와 **파일:라인**, **수정 제안**과 함께 보고한다.
4. 확실하지 않은 항목은 추측하지 말고 "확인 필요"로 표시한다.

## 중점 도메인

- `auth` — JWT 검증, 토큰 만료/서명, OAuth2 콜백 처리.
- `payment` — 금액 위변조, 멱등성, 외부 결제 검증.
- `reservation` — 권한 없는 예약 조회/취소, 동시성.
- `member` — 개인정보(이름/전화번호) 노출, 권한 상승.

세부 점검 항목은 `checklist.md` 참고.
